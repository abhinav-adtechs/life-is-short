Locked down by default

Your list is a map of your life.
It's protected like one.

🔐

PIN + a second step

An authenticator code, Face ID or a passkey. No sign-up page, no email links to phish.

🛡️

The database checks it

Row-level security returns nothing unless this session passed both checks.

🧱

Strict by default

A per-request CSP nonce, HSTS, no framing. Claude's tokens are stored only as hashes.

🌙

Nightly backup

To a second database in another region, breach-checked before every copy.

Open source · MIT

Run your own copy.

One person, your own database, nobody else's app. No keys needed to try it.
